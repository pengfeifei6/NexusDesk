# NexusDesk W04 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task. Steps use checkbox syntax.

**Goal:** 完成原子领取、真实并发验证、Vue 业务闭环、G1 演示及整周学习材料。

**Architecture:** 复用 Go 分层及事务边界；领取用专门条件 UPDATE；Vue 使用单一 HTTP 客户端和内存登录态。隔离 PostgreSQL + 浏览器验证真实链路。

**Tech Stack:** 现有 Go/Gin/pgx/PostgreSQL17；Vue3/TS/Pinia/Router/Vitest；独立 Node24.12.0。

**Spec:** [W04手册](../../../项目开发文件/每周开发手册/07_NexusDesk_第四周详细开发手册.md)、[领取契约](../../api/ticket-claim.md)、[ADR](../../decisions/0004-atomic-ticket-claim.md)、[前端范围](../../frontend/web-mvp.md)。

## Global Constraints

- 不读取/改写真实 .env；不自动stage/commit/push/merge/部署；不改原始手册和现有迁移/Go依赖。
- 仅active admin/member；同组织/未删除/OPEN/未指派/版本匹配；领取200保持OPEN/version+1/一条事件；冲突409 TICKET_CLAIM_CONFLICT；不可见404。
- 原有 W01～W03 权限及状态机保留。前端无持久Token，无假数据。独立测试资源清理仅限本次所有。

## Review Focus

1. UPDATE零行必须区分安全404/409，异常不能吞成冲突。
2. 高并发/版本上限/事件与提交失败不能产生部分成功。
3. 新会话/新组织不能被旧响应覆盖或误登出。
4. JS int64、网络失败及取消不能损坏身份/版本或卡住页面。
5. 浏览器与录屏/日志不得泄露密码或Token；表单输入应可恢复。

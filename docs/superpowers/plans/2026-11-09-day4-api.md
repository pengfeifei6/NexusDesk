# Day 4 最小 API 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从环境变量加载配置，启动 Gin，提供 HTTP 200 的 `/healthz`，明确报告启动失败。

**Architecture:** 配置、路由、启动入口分别独立。Day 4 只读取数据库配置，不连接数据库。使用标准库 HTTP Server 管理监听、超时和信号退出。

**Tech Stack:** Go 1.26.1、Gin v1.12.0、标准库 testing / httptest。

**Spec:** [第一周手册 Day 4](../../../项目开发文件/每周开发手册/04_NexusDesk_第一周详细开发手册.md)、[架构](../../architecture.md)。

## Review Focus

- 必要变量缺失或空白时，错误指出变量名且不泄露密码。
- HTTP 地址和数据库端口非法时，启动前明确报错。
- 密码保留原始内容，不因统一裁剪配置而改变值。
- 端口占用时返回失败，不留下后台服务。
- 信号退出时关闭监听，`/healthz` 无数据库依赖。

# 第十周：AI 评测与企业工作台设计

依据原始《12周开发周期与求职计划》第十周及用户追加的前端美化要求，由 AI 代为实现；人工标签复核和个人掌握不代称完成。

## 范围与决定

- 现有精确向量检索作为默认基线，新增显式可选 `retrieval_mode: hybrid`：最多 20 个向量候选、20 个词项候选，用 RRF（常数 60）融合，chunk ID 稳定打破同分。词项为英文标识符及中文双字片段，去重最多 32 个；SQL 参数化 substring 匹配，不宣称 BM25。两路均沿用余弦最低 0.40 与全部当前来源条件，不新增 ANN/迁移/依赖。
- API 检索与问答可传 `retrieval_mode: vector|hybrid`，省略为 vector；响应明确返回所用模式。原有 AI search tool 仍走默认策略，不增加模型可控权限参数。
- 问答返回 `usage`（供应商实际 prompt/completion/total tokens、可选 cache hit/miss；缺失为 unknown/null，不能按字符伪造）和 `timings`（embedding_ms/search_ms/generation_ms/total_ms）。记录实际响应模型名。无召回跳过生成时注明未调用、token 为零；未返回 usage 的模型响应仍兼容。
- 引用改善：模型提示要求最小充分证据、针对问题且不附无关引用；保留供应商发送白名单与服务端前后全量来源复查。前端来源卡展示引用序号、文件、原文、范围和向量相似度，让用户可以核对。引用有效不等于语义蕴含，评测分别记录。
- 固定 60 道合成题（事实、改写、多证据、精确标识符、无答案、跨组织），至少 8 个文档。模型运行前冻结语料/问题/证据区间 SHA256。原 W06 20 题保留为历史，禁止看结果后改标签。精确向量 vs hybrid 各跑全部题；固定问答子集覆盖正例、所有负例，记录模型错误、引用相关率、拒答、耗时、tokens 和有来源的费用估算。
- 生产界面使用浅灰背景、白色内容卡、深色侧栏、克制的蓝色强调；系统字体、清晰标题层级、紧凑表格、状态标签、统一表单/空态/错误/加载。桌面侧栏与移动导航、登录/注册、组织入口、工单、知识库、检索、AI 对话整体改造；不添加虚构统计或无功能按钮。
- `docs/rag-evaluation.md`、机器可读原始数据、脚本、W10手册、周报/问答/演示共同交付。MCP/Eino 仅说明边界，保持现有受控 native tools。

# NexusDesk 第七周阶段介绍

本周从同步知识库处理推进到可观察、可恢复的后台文档任务。用户上传 TXT/MD 后，可直接提交异步处理，由独立 Worker 提取正文并建立索引，页面显示状态和尝试次数，失败后按权限重试或取消。

工程结构已增加5个任务API、一条迁移和一张任务表：共33个业务API、1个健康检查、11张业务表、11条迁移，仍是8个主页面，在知识库详情嵌入任务面板。实际验收状态见[第七周记录](weekly/week07.md)。

## 已有能力

- 身份认证、组织成员隔离、工单/评论/事件、原子领取和基本工作台。
- 私有上传/下载、TXT/MD正文、独立索引状态、pgvector精确检索、带真实来源的非流式问答。
- 持久任务、Redis/Asynq、独立Worker、租约/心跳、三次退避重试、去重、取消与崩溃后核验恢复。
- 本周新增API有对应页面操作；历史成员管理、工单PATCH编辑/指派/删除仍没有全部补齐UI。

## 日常维护

修改业务前先确认组织授权、数据库约束、状态与事务边界。新表用新迁移，不改历史 SQL；新任务类型不要只复制消息格式，还要定义幂等、权限、失败和恢复。维护数据库和私有文件的配套备份，Redis不能替代业务备份。旧二进制应停止后再使用新版Worker。

默认服务为 API8080、前端5173、PostgreSQL5432、专用Redis6380、Ollama11434；实际以各终端已加载配置为准。应用不自动读取.env，也不自动迁移。故障先看固定错误码和任务状态，不把清队列、删卷、批量重置当成常规操作。

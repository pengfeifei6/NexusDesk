# 第十二周演示：实际录屏与自己演示的方法

已生成 **5 分 19.00 秒**的实际浏览器视频：[nexusdesk-demo.webm](../testing/evidence/week12/nexusdesk-demo.webm)，另有[字幕 VTT](../testing/evidence/week12/nexusdesk-demo.vtt)、[实际章节时间](../testing/evidence/week12/demo-chapters.json)和[容器时长核验](../testing/evidence/week12/video.json)。本机浏览器或视频播放器可打开 WebM。

录屏由自动化操作真实 Vue/API/PG/Redis/Worker 生成，七章字幕在浏览器画面中展示。没有旁白；不是开发者本人讲解能力的证明。账号、组织、工单与文档均为合成数据；模型采用确定性本机 HTTP 夹具，不访问 DeepSeek，也不代表语义质量。视频独立跑过完整浏览器断言，见[结果](../testing/evidence/week12/demo.json)。

## 5～8 分钟讲解稿

| 时段建议 | 操作与讲解 |
|---|---|
| 0:00～0:50 | 注册、创建组织、添加已注册成员。说明 user 与组织成员分离，角色由服务端查询 |
| 0:50～1:40 | 创建工单、编辑、指派。说明 expected_version；演示过期修改409刷新，不覆盖他人结果 |
| 1:40～2:25 | 领取、开始处理、评论和事件。解释数据库条件与同事务事件 |
| 2:25～3:10 | 上传 Markdown、Worker 任务完成、正文预览/下载。说明 PG 真相、Redis通知和租约 |
| 3:10～4:00 | 混合检索、引用回答。区分链路演示与真实模型评测；点击原文核对 |
| 4:00～4:50 | AI 提议创建工单，确认前无写入，确认后出现结果链接。说明模型权限边界 |
| 4:50～5:40 | 手机布局、普通成员无管理能力、删除取消与确认、切换组织清空旧内容；介绍维护与交付边界 |

手工讲解可按节奏延长到 6～7 分钟；实际自动版的准确时间以章节 JSON 为准。若要展示个人能力，用同样合成数据自己操作并旁白，重点讲“并发领取”和“Worker 崩溃恢复”，不读稿也能说明代码位置与限制。

## 重新生成

先按[运行指南](../release/quickstart.md)安装依赖与 Chromium，然后：

```bash
python3 scripts/week12-smoke.py --web-only --demo
```

运行约 6 分钟，创建随机独立测试环境，结束后清理自己的容器和进程，视频写入同一路径。每次覆盖 W12 演示文件，想保留旧版先另存。视频文件约 32 MB，不进入精简源码包；主仓库包含证据时才可打开上述相对链接。

无需真实 `.env` 或云 Key。快速浏览器验收不录视频、不等待字幕，使用 `--web-only`。主服务无需停止。

# NexusDesk 阶段介绍：第十周

NexusDesk目前是一个可本地运行的多组织工单、知识库与受控AI协作系统。第十周在原主目录继续完成AI评测能力，并统一重做现有前端工作台。它是具有完整业务闭环和真实验收证据的学习/工程项目，尚未作为公网生产服务部署。

## 可以使用的能力

注册和登录后，用户可以创建或选择组织，创建/查看/领取工单，进行状态流转、评论和事件追溯；管理员与普通成员的操作由后端当前成员关系检查。

知识库支持TXT/Markdown/PDF上传下载，TXT/Markdown可提取正文并建立向量索引；后台Worker有任务状态、有限重试与租约恢复。检索结果限定当前组织及有效正文版本，用户可选择精确向量或混合检索，再基于来源生成回答。

AI对话支持流式回复、知识检索和工单读取工具，并可以提出新建工单建议。用户确认服务器保存的提议后才真正建单，模型本身没有确认写入权限。会话属于当前创建者，即使组织管理员也不能任意读取他人的私人会话。

列表缓存采用数据库版本防止旧数据重新填充，AI发消息有组织/用户范围的限流。前端有相应稳定错误提示，组织切换和退出会清理保护内容并忽略过期请求。

## 第十周新增

- 60题固定评测集、双策略对照、来源区间指标、拒答/隔离测试和费用观测，结果可用脚本复跑。
- 混合检索使用有界词项候选和向量排名融合，不引入新框架或近似索引；默认向量以保持已有行为。
- 问答返回供应商实际Token和阶段耗时，来源卡可核对文件与原文。缺失用量保持未知，不编造成本。
- 所有现有页面统一工作台布局、导航、表格、表单、空态与状态展示，并覆盖桌面和手机。

本次小型合成评测中，Recall@5从95.19%提高到99.04%，MRR@5从0.8317提高到0.8901；仍存在多证据覆盖不足与引用区间不完整案例。数字的语料、分母和局限见 [评测报告](rag-evaluation.md)，不要脱离样本规模使用。

## 规模与技术

仍为39个业务API＋健康检查、14个迁移、14张业务表＋缓存版本表、9个主页面。技术栈沿用Go/Gin/pgx/PostgreSQL+pgvector、Redis/Asynq、Vue/TypeScript/Pinia；BGE在本地生成向量，现有配置使用DeepSeek生成回答。没有微服务拆分，没有为了展示技术名词引入MCP/Eino。

开发、测试和运行都在 `/media/yjz/pzp/Go/projects/NexusDesk`。配置和密钥只在本地环境，测试使用自有随机PG/Redis及合成资料。运行方法见 [W10演示](demo/week10-demo.md)，逐项完成与验证见 [W10周报](weekly/week10.md)。

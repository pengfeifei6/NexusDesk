# NexusDesk 最终项目介绍：十二周本地交付版

NexusDesk 已形成一套可以在本机运行和维护的组织工单、知识库与受控 AI 工作台。当前有 **39 个业务 API、14 个迁移、15 个业务/技术表、10 个主要页面**。Go API、独立 Worker、PostgreSQL/pgvector、Redis 与 Vue 前端协作，生成模型支持已接入的 DeepSeek，本机 BGE-M3 提供向量。

## 普通用户与管理员可以做什么

用户注册登录后创建组织，或让管理员按账号编号加入组织。组织内可以创建、查看、领取、流转和评论工单；创建者/admin 可以编辑 OPEN 工单，管理员可指派和解除受理人、确认软删除。W12 把成员和工单管理页面补齐，不再要求通过 curl 才能使用这些既有功能。

知识库支持 TXT/Markdown 私有上传、异步提取索引、预览下载、任务状态/重试/取消。检索页可选择精确向量或混合检索，问答返回来源。AI 会话支持流式显示和受限工具；创建工单先有提议，人工确认后服务端重新核验再写入。前端同时支持桌面和390px移动布局。

## 已完成的工程能力

身份与组织权限分离、JSON bigint 无损、组织/路由/会话切换旧响应隔离；工单版本冲突与同事务事件；PG 持久任务与 Worker 租约恢复；文档和索引版本核对；元数据缓存与共享 AI 配额；安全请求日志和本机 metrics/pprof/trace。具体取舍与代码导航见[当前架构](release/architecture.md)。

W10 保存真实模型评测，W11 保存性能 profile/对比和故障恢复，W12 完成当前前后端回归与交付整理。测试是多个层次，不能互相替代：本周真实库 Go race1181 PASS节点、286顶层、0Skip；前端163项、Python34项、九组浏览器流程。证据见[W12记录](weekly/week12.md)，语义与性能结论见各自报告。

## 现在怎样查看

已有服务正常时直接打开 http://127.0.0.1:5173。需要启动时，在项目根目录的三个终端分别运行 `python3 scripts/dev.py api`、`python3 scripts/dev.py worker`、`python3 scripts/dev.py web`。已有 .env 保留，缺配置/数据库/模型的全新环境按[运行指南](release/quickstart.md)初始化。

先看[5分19秒实际字幕演示](demo/week12-demo.md)，再按页面自行创建测试组织和工单。看懂代码按 main → Handler → Service → Repository；日常修改和排错照[维护手册](release/runbook.md)。

本地源码包包含前后端、迁移、锁文件和 Markdown 文档，放在 `.local/releases`，附逐文件清单和 SHA256；它不含真实配置、上传、备份、依赖缓存或视频证据。原始测试/视频保留主仓库。交付记录见[清单](release/checklist.md)。

## 完成范围与后续

这是十二周求职 MVP 的完整本地交付，不宣称公网生产服务。PDF提取、SSO、角色修改、无限AI历史、长期监控告警和跨机高可用未实现，详见[功能矩阵](release/acceptance.md)。本次未创建其他开发目录、未自动 Git 提交/推送、未公开部署；没有重写原迁移或依赖锁，也没有用真实云调用重复收费验收。

AI 按明确委托参与了开发和整理。你后续需要亲自审阅、独立解释两项技术难点、人工复核评测标签，并决定提交和公开方式。[简历素材](release/resume.md)与[12个深入问题](release/interview.md)用于帮助你学习和准备，不能代替个人能力证明。

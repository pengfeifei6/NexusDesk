W12 在已有后端契约上补齐成员及工单管理 UI，没有添加新的业务 API。共 39 个规范业务接口、14 迁移、10 个主要页面：登录、注册、组织工作台、工单列表/详情、成员、知识列表/详情、检索问答、AI 对话。路由尾斜杠别名、healthz 和诊断接口不重复算业务 API。

## 验收口径

W12 的 Go race 使用真实随机 PG/Redis，1181 PASS 节点、286 顶层测试、0 Skip。前端 163 项、Python 34 项、构建/lint/格式检查和 9 组浏览器流程通过。完整证据在[周报](../weekly/week12.md)；浏览器模型是确定性本地 HTTP 夹具，云调用为 0，不能充当语义准确率。

W10 已保存固定语料的真实 BGE/DeepSeek 评测，标签是 AI 预标注、人工复核待办；W11 保存性能与故障恢复证据。W12 未重新消耗云 API 复跑语义评测，也未重复不受此次前端改动影响的全部性能实验。

## 明确未实现

- PDF 正文提取：只允许验证签名后的上传/下载，处理返回 PDF_UNSUPPORTED。
- 成员角色修改、停用、退出组织、邀请邮件、support 角色、SSO、找回密码和刷新 Token。
- AI 历史分页/归档：会话列表最新 50，消息和 action 各最新 100；不得说“无限历史”。
- ANN、BM25、精确 tokenizer 计费、大规模语义质量承诺。
- 长期指标持久化、告警、分布式追踪、自动跨介质备份、跨机高可用。
- 公网部署、域名/TLS、公开仓库发布和真实用户运营。注册/登录仍需可靠防滥用等公开部署准备；回环限制不能直接删除。

“十二周完整交付”以本地可运行的求职 MVP 为范围。原始蓝图中的远期模块不能因文档打勾变成已实现；开发者脱离 AI 独立解释/演示也需本人完成。

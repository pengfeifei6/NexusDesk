# W05 原创测试样例集

十份由 AI 为本项目编写的虚构 TXT/Markdown 文档，不含真实公司资料或个人秘密。组织 A/B 是隔离验收中的逻辑分组，不是开发库固定 ID。

[index.json](index.json) 保存标题、组织归属和期望解析状态。第五周浏览器验收通过真实 API 上传并处理所有样例，将实际文档 ID、组织 ID、摘要和 READY 状态写入 `docs/weekly/evidence/week05-sample-manifest.json`。测试库会清理，因此清单是一次运行证据，不代表这些 ID 在日常数据库仍存在。

可在自己的知识库页面手动选择这些文件进行演示；不要把数据库 Token 或真实私有上传内容复制进本目录。

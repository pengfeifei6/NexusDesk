# W02 Day 7 整周只读安全审查

- 日期：2026-11-10；依据：第二周手册Day7、认证/API/权限/Repository契约和AGENTS。
- 方法：独立代理静态只读审查，主代理负责实际运行；未读取真实.env、修改文件、运行测试/漏洞扫描或操作数据库/Git。
- 结论：未发现需修复的P0～P3实质安全问题，未发现阻断Day7的测试覆盖缺口。

## 1. 核对范围与结论

| 范围 | 已核对的边界 |
| --- | --- |
| 密码与注册/登录 | Argon2id固定参数、异常编码成本限制、共享两名额、取消、dummy、规范化邮箱与真实唯一索引 |
| JWT | 固定HS256、签名、必需sub/iss/aud/iat/exp、整数时间、900秒和8KiB预算，错误不带原Token |
| 可信身份与路由 | 验签后账号存在性，私有Context仅ID，公开/受保护Group边界、严格Bearer |
| 组织/成员事务 | 同tx组织/admin及目标显示名/成员添加，COMMIT后返回、独立且有界回滚 |
| RBAC与租户范围 | 先认证/成员/角色再业务输入，SQL限定组织，disabled统一404、member写403、重复409 |
| 输入、DTO与错误 | 参数化SQL、严格JSON/Unicode/整数/分页，公开DTO、指定约束分类、安全500与应用日志路径 |
| 配置与迁移 | Base64解码、十二变量、回环限制，users与成员增量SQL/唯一/FK/CHECK，不改历史迁移 |
| 测试运行器 | 专用库前缀/回环/显式开关、随机Compose归属清理、--closeout模式与内存过期Token演示 |

审查时对照Day6清单58文件，57项一致，唯一变化为运行器新增--closeout。之后AGENTS及文档更新阶段状态；演示夹具改为一次采样时间，保证iat/exp恰差900秒，并由主代理重新运行最终新目录演示。业务Go代码、依赖和迁移未改动。

## 2. 结论的适用范围

这是一轮源码与契约静态检查，不等于漏洞数据库扫描、模糊测试穷举、动态渗透或生产安全认证。当前只面向回环本地学习；可靠限流、会话撤销、HTTPS、邮箱所有权等按 [ADR](../decisions/0002-auth-security.md) 继续作为发布前待办。

每请求查当前成员关系不承诺并发撤权完全线性化；角色/状态修改接口不在本周范围。历史Day3/4的四项已修复边界问题及证据保留，没有因本次未发现新问题而删除或改写。
